JAWABAN EKSPERIMEN PRAKTIKUM 6
P02 - PERPUSTAKAAN MINI

1. Eksperimen Menambahkan Objek Koleksi

Kode:
Koleksi x = new Koleksi("X01", "Uji", 2026);

Jawaban:
Akan muncul error dari compiler karena class Koleksi merupakan abstract class, sehingga tidak dapat dibuat objek secara langsung menggunakan new Koleksi(...). Class abstract hanya dapat digunakan sebagai superclass dan harus diwarisi oleh class turunannya.


2. Eksperimen Mengubah Nama Method hitungDenda

Perubahan:
Method hitungDenda pada class Buku diubah menjadi hitungdenda.

Jika anotasi @Override tetap ada:
Compiler akan menghasilkan error karena method hitungdenda tidak dianggap sebagai override dari method hitungDenda pada superclass. Java membedakan huruf besar dan huruf kecil pada nama method.

Jika anotasi @Override dihapus:
Program dapat dikompilasi, tetapi method hitungdenda bukan merupakan override dari method superclass. Method tersebut menjadi method baru pada class Buku, sedangkan method hitungDenda dari superclass tetap digunakan.


3. Eksperimen Menambahkan Buku dengan Judul Kosong

Kode:
new Buku("B009", "", 2020, "Anonim");

Jawaban:
Program tetap dapat dibuat dan dijalankan apabila constructor Buku tidak memiliki validasi terhadap judul kosong. Akibatnya, objek Buku dengan judul kosong tetap dapat ditambahkan ke daftar koleksi. Buku tersebut tidak memiliki judul yang dapat dicari secara normal.


4. Eksperimen Mengubah Status Menjadi Public

Perubahan:
private StatusKoleksi status diubah menjadi public, kemudian status B002 diubah langsung dari main menjadi TERSEDIA saat masih dipinjam.

Jawaban:
Hal tersebut melanggar prinsip enkapsulasi. Atribut status seharusnya bersifat private agar perubahan status hanya dapat dilakukan melalui method yang disediakan oleh class, seperti method peminjaman dan pengembalian. Jika status dibuat public, main dapat mengubah status secara langsung dan dapat membuat kondisi objek tidak sesuai dengan aturan peminjaman.
